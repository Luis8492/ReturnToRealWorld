# Return To Real World

用もないのにブラウザを開いて、ついニュースフィードを眺めてしまう。それを防ぐための「ブラウザのホーム画面」です。

画面の真ん中にある **Return To Real World** ボタンを押すと、地平線まで続く地面と空の中に、変なポーズの人形が少し斜めを向いて現れます。そのポーズを真似して、じっと静止してください。

人形の手足は左右で色を変えてあります。向かい合って鏡のように真似するので、**青い手足があなたの右手・右足、オレンジが左手・左足**です。同じ色の側の手足を、画面のとおりに動かしてください。

- 20秒かけて太陽が昇って沈む（ポーズ1つ目）→ 右の葉っぱが点灯
- もう一度太陽が昇って沈む（ポーズ2つ目）→ 左の葉っぱが点灯
- `bye.`

それだけです。終わったあと画面をタップすると最初のボタンに戻ります。

## ランダムなポーズの作り方

ポーズは毎回その場で生成します（`js/pose.js`）。条件は次のとおりです。

- **関節の可動域**: 首・背中（腰椎と胸椎）・肩・肘・手首・股関節・膝・足首に、人の可動域にもとづく範囲を設定。肩や股関節のような球関節は「振り」と「ひねり」に分け、振りの組み合わせは楕円状の範囲で制限しています。
- **少なくとも片足がぺたりと地面につく**: 立っている足を足裏が水平になるように地面へ置き、そこから体を組み立てます。両足立ちのときは、もう片方の足も足裏が水平に接地するように逆運動学で合わせます。
- **重心が足の上にある**: 片足立ちなら重心がその足裏の上、両足立ちなら両足の間に来るよう、足首・膝・股関節・腰を逆運動学（減衰最小二乗法）で調整します。
- そのほか、地面にめり込まないこと、手足が体を突き抜けないことも確認しています。

ふだんは「ほどよく変」なポーズで、5回に1回くらい「かなり変」なポーズが出ます。関節の角度は可動域の端のほうに寄せてランダムに選び（かなり変なときほど強く寄せる）、両足立ちでは足を大きく開いたり腰を落としたりする姿勢も目標にします。そのうえで条件を満たす候補をいくつか（ほどよく変は3つ、かなり変は6つ）作り、「変さ」が一番大きいものを選びます。変さは、関節の振れ幅・体幹の傾き・首の傾き・浮かせた足の高さ・手足の広がり・腰の低さから計算します。

## 手だけ版（`hands.html`）

会社のPCのように立ち上がれない場所向けに、座ったまま机の上で両手だけでできる版もあります。`hands.html` を開いてください。

自分の目から机の上の手元を見下ろした画面に、木製の腕と手が現れます。自分の手を見ているのと同じ向きなので、左右はそのまま **青があなたの右手、オレンジが左手** です。手のひら側だけ塗らずに木の色にしてあるので、手のひらの向きもわかります。太陽は画面に映らず、机に落ちる影の向きと光の色で一日が過ぎていきます。ポーズ2つ・葉っぱ・`bye.` の流れは全身版と同じです。

動かすのは肘から先だけで、肘は机についたままです。

- **前腕の左右**: 肘を支点に、まっすぐ前から体の前を横切るところまで内側に振る。気をつけの姿勢より外側へは開かない
- **手のひらの向き**: 下・横・上
- **手首**: 上下に曲げる（少しだけ横にも）
- **指と親指の形**: グー、パー、指差し、ピース、キツネ、OK など

ポーズは毎回その場で生成します（`js/hand-pose.js`）。条件は次のとおりです。

- 関節の可動域の中に収まる
- 机にめり込まず、両腕が突き抜け合わない。腕が交差するときは上の腕がもう一方の腕に乗る（両手が触れ合うポーズもあります）
- 手で作れる指の形だけにする: 薬指は中指か小指と同じ形にそろえ、中指だけを立てる形は出さない。人差し指や中指だけを曲げる、薬指を伸ばしたまま小指を曲げる、といった少し難しい形は出にくくしている
- 見下ろしたときに、片方の手がもう一方の腕に隠れない

全身版と同じく、5回に1回くらい「かなり変」なポーズ（腕の交差が多め、手首や手のひらの向きが大きめ、指を鉤状に曲げる形など）が出ます。

## 自分のブラウザのホームにする

GitHub Pages で公開したURL（下記）を、ブラウザの「ホームページ」や「新しいタブ」に設定してください。手だけ版は末尾に `hands.html` を付けたURLです。

## GitHub Pages で公開する

ビルドは不要です。HTML / CSS / JavaScript と、同梱した [three.js](https://threejs.org/)（`vendor/three/`）だけで動きます。

1. このブランチを `main` にマージする
2. GitHub のリポジトリで **Settings → Pages** を開く
3. **Build and deployment** の Source を **Deploy from a branch**、Branch を **`main`** / **`/ (root)`** にして Save
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/`（手だけ版は `.../hands.html`）で開けるようになります

## 手元で動かす

ES Modules を使っているので、`index.html` を直接開くのではなく簡単なサーバー経由で開いてください。

```sh
python3 -m http.server 8000
# http://localhost:8000/ （手だけ版は http://localhost:8000/hands.html）を開く
```

開発用のURLパラメータ:

- `?seed=123` … ポーズを固定する
- `?t=20` … 指定した秒数から始める（全体は約50秒）

どちらの版でも使えます。

テスト（ポーズが制約を満たしているかの確認）:

```sh
node --test
```
